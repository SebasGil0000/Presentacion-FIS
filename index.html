Introducción

Contexto y Problemática del Negocio

El Problema

Estudiantes autodidactas no detectan sus propios errores al leer en voz alta.

  • Falta de retroalimentación inmediata
  • Dificultad para saber qué palabra falló
  • Fricción al grabar y escuchar audios

La Solución: SayIt

App web que escucha al estudiante y ofrece feedback cromático en tiempo real.

  • Evaluación instantánea palabra por palabra
  • Feedback visual (Verde/Rojo)
  • Métricas automáticas

Objetivos del Proyecto

Objetivo General

"Desarrollar una app web interactiva que evalúe y mejore la pronunciación del inglés mediante retroalimentación visual en tiempo real usando IA."

Captura

Captura de audio directo desde el navegador.

Integración

Motor de reconocimiento (Azure Speech API).

Feedback

Interfaz visual que marca aciertos/errores.

Justificación

¿Por qué SayIt es viable y necesario?

Impacto Educativo

Actúa como "espejo fonético", acelerando el aprendizaje mediante condicionamiento visual y gamificación.

Viabilidad Técnica

APIs modernas reducen latencia y costo. Permite un producto web ligero sin instalar software pesado.

Alcance y Delimitación

Alcance

  • Catálogo predefinido de textos.
  • Captura y transcripción en tiempo real.
  • Comparación palabra por palabra.
  • Feedback dinámico (Verde/Rojo).
  • Métricas de precisión finales.

Fuera del MVP

  • Análisis de entonación o acento.
  • Soporte offline (requiere internet).
  • Carga de textos personalizados.
  • Navegadores sin soporte MediaRecorder.

Sostenibilidad del Proyecto

Costos operativos y modelo de crecimiento

Costos Operativos

  • Azure Speech API: ~$0.0167 USD por minuto de audio procesado.
  • Servidor backend: Hosting cloud para API REST (~$10-15 USD/mes).
  • Base de datos: PostgreSQL básico para sesiones y métricas (~$5 USD/mes).

Estrategia de Crecimiento

  • Freemium: Acceso gratuito limitado para atraer estudiantes.
  • Suscripción Pro: Funciones avanzadas para cubrir costos operativos.
  • Licencias institucionales: Convenios con escuelas de idiomas (B2B).

Aseguramiento de Calidad

Confiabilidad del sistema

Pruebas Estructurales

  • Unitarias: JUnit + Mockito para el algoritmo de comparación fonética.
  • Integración: Latencia < 500ms en comunicación con Azure Speech API.

Resiliencia

  • Validación de permisos de micrófono.
  • Control de desconexión (cierre seguro).
  • Separación estricta Frontend/API.

Validación con Usuarios

Elicitación de requisitos y pruebas de prototipo

Elicitación

  • Muestra: Estudiantes de inglés niveles A1–B2.
  • Hallazgo clave: El 92% reporta la falta de feedback inmediato como el mayor obstáculo para mejorar su pronunciación.

Validación de Prototipo

  • Pruebas de usabilidad sobre el mockup funcional.
  • Usuarios confirmaron que el código de colores (Verde / Amarillo / Rojo) reduce la ansiedad al hablar.
